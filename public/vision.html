Vision

A trusted base for the machines that act in the world.

Our long-term aim is an Indian-owned operating system stack, from the system call to the silicon, for the small controllers inside drones, robots and industrial equipment. We get there one proven layer at a time.

The path, layer by layer

1 · Proven kernel

Done in alpha: isolation, signed apps and a power-loss-safe store, shown on a real board.

2 · Shippable security

Next: secure boot, a locked debug port, field updates and an outside review, so a maker can ship it.

3 · Products with partners

Reference designs built with device makers, who ship MAATAA OS inside their own products under licence.

4 · Indian silicon

Later, and only past a decision gate: the Panini derivation core on an FPGA, then a test chip.

Planned product directions

What we plan to build, with partners.

Beyond the controller

Language and silicon.

Panini engine

Sanskrit sandhi as a signed app today, with every answer naming the sutra that produced it. It shows the OS running real rule-based software on a small chip.

Derivation core in RTL

A Verilog core that derives verb forms by Paninian precedence; it matches the reference on all 1,042 forms in simulation. To our knowledge, after a search, none has been published before.

What we will not claim

No safety certification, no production readiness and no silicon until each is done and shown. The roadmap lists the gate for each step.
