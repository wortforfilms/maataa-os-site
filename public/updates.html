  • Board run4 Nov 2026

    Board runs for alpha.9: power cuts, priority inheritance, Panini 10

    Run on the NUCLEO-F411RE with the development key.

    • Store survives power loss: three runs, 9 USB cable pulls during writes; each time key 63 held the last acknowledged value or the one in flight. All PASS.
    • Priority inheritance: with it, the high-priority task gets the lock before the middle one finishes; without it, the low task starves holding the lock. Both kernels behaved as expected; the normal kernel was flashed back.
    • Panini capsule 10 installed by a signed commit: hare + iha gives hara iha (rule 10, 8.3.19), the same as the host library.
  • Release3 Nov 2026

    Release 0.1.0-alpha.9

    Evidence release for QEMU and the NUCLEO-F411RE. System calls, the host-channel protocol and the sandhi wire format are unchanged.

    • Sandhi: 8.3.19 after ayadi; e and ai drop the y, o and au keep the v.
    • The store-full error is now checked through the system call itself.
    • A CI check compares the docs with the code on every push; QEMU smoke test 15 of 15.
  • Release3 Nov 2026

    Release 0.1.0-alpha.8: signed host requests

    Security release.

    • Committing an app install, removing the installed app and writing a task's store key now need an ed25519 signature over a fresh per-boot challenge, so recorded requests cannot be replayed.
    • Each store key is written only by its owner: the host channel, or an app by its signed name. Reads stay open by design.
  • Release2 Nov 2026

    Release 0.1.0-alpha.7: consolidation

    No change to system calls or the wire format.

    • Engineering docs written from the source: system-call ABI, memory map, threat model, rule and evidence registries.
    • Code no build used was removed, and more smoke checks were added, including MPU faults.
  • Release2 Nov 2026

    Release 0.1.0-alpha.6: Panini capsule 8

    New sandhi rules in both the capsule and the host library, and a release script that refuses to create a missing signing key by accident.
