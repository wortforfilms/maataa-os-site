Portfolio · proposed

115 product concepts, sorted by what MAATAA OS must become to run them.

These are concepts, not released or validated products, and every picture is a concept render. The shared base is MAATAA OS, flexible PCB design, compute modules, security, connectivity and device management. Each product carries a tier: how far the OS must grow before it can run it.

The five tiers

Most of the list is microcontroller work.

44 A · today's MCU class

Runs on today's microcontroller class once the production security profile is done.

26 B · bigger MCU + radio/network

Needs a bigger microcontroller with a network or radio stack, or a small screen: 1.5–3 years.

12 A + C · MAATAA inside

A whole machine: MAATAA OS runs its motor, safety and I/O controllers; its main computer runs Linux.

26 C · application processor

Needs a Linux-class processor. MAATAA OS runs only a controller inside it, if any.

7 H · hardware only

Hardware or vendor firmware; no operating system of ours.

⚑ marks products that need safety, regulatory or payment certification before sale. Desktop, tablet and phone are listed for completeness: they need a desktop or mobile OS, and MAATAA OS will not become one. Download the full list (CSV).
